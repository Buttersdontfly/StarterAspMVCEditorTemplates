# samples

Committed output of `dotnet new starterasp-mvc` for each option combination.
Generated by `../build/Regen-Samples.ps1` — do not edit by hand.

CI regenerates these and fails if the result differs from what is committed.
That makes every template change visible as a diff in the PR, per combo, which
is the main defence against generation silently breaking.

- `identity/` — `--auth identity` (the default)
- `none/`     — `--auth none`
